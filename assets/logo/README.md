# Foreca logo — условия использования

Файл `foreca-wrc.png` — официальный логотип Foreca в версии WRC
(white/red/cyan) для размещения на тёмном фоне.

Источник: https://business.foreca.com/logo

Требования, которые обязан соблюдать сервис:

- логотип или имя Foreca отображается вместе с погодными данными как атрибуция;
- фон под логотипом плоский или слабо градиентный, без фотографий;
- вокруг логотипа остаётся свободное поле не меньше половины его высоты;
- на тёмном фоне используется версия WRC, на светлом — BRC;
- логотип не используется отдельно от данных Foreca;
- нельзя создавать впечатление партнёрства, спонсорства или одобрения со стороны
  Foreca без отдельного разрешения.

Логотип не является частью лицензии на код проекта: права принадлежат Foreca Ltd.
Файл включён в репозиторий исключительно для выполнения требования атрибуции
при использовании Foreca Weather API.
