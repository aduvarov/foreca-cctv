# Tasks

Ветки по capability. Порядок групп — порядок зависимостей: фундамент -> данные ->
конфигурация -> кадр -> поток. Каждая группа соответствует ветке и одной capability
из proposal; фундамент capability не является и живёт в `main`.

- Группа 0 — `main`
- Группа 1 — `feat/foreca-forecast`
- Группа 2 — `feat/service-configuration`
- Группа 3 — `feat/weather-chart`
- Группа 4 — `feat/rtsp-stream`
