# Proposal

## Why

На объекте с видеонаблюдением оператору нужен прогноз погоды на неделю прямо на мониторе охраны, без отдельного ПК, браузера и веб-интерфейса. Аппаратный видеорегистратор (NVR) умеет только забирать RTSP-поток с камеры, поэтому погодный экран должен выглядеть для него как обычная камера. Сервис превращает данные Foreca Weather API в непрерывный видеопоток с графиком недели.

## What Changes

- Появляется сервис на Node.js/TypeScript, который при старте проверяет конфигурационный файл и при его отсутствии запускает интерактивный мастер: спрашивает токен Foreca и локацию, проверяет токен запросом и сохраняет конфиг.
- Сервис периодически (по умолчанию раз в 30 минут) запрашивает почасовой прогноз с шагом 3 часа (`/api/v1/forecast/3hourly/{location}`) и метаданные локации (`/api/v1/location/{location}`) и строит доменную модель недели: 7 суток от ближайшего 3-часового шага, первый день — неполный («сегодня»).
- Сервис рисует кадр 640x480: заголовок с названием локации, дни недели и даты, иконки погоды день/ночь, непрерывная кривая температуры, точки минимума/максимума по дням, осадки за 6 часов, ветер по дням, время обновления данных и логотип Foreca как обязательная атрибуция.
- Кадр публикуется как RTSP-поток H.264 (Main, yuv420p, 1 fps, CBR) через FFmpeg в MediaMTX. Наружу отдаются две ссылки на один и тот же поток: основной путь и его алиас.
- При недоступности Foreca, падении FFmpeg или отсутствии сети сервис не прекращает вещание: показывается последний успешный прогноз с признаком устаревания, а при полном отсутствии данных — offline-заглушка средствами MediaMTX.
- Типы и валидаторы ответов Foreca генерируются из `foreca-weather-api.openapi.json` через `@hey-api/openapi-ts` с плагином zod; рукописные типы API не пишутся.

## Capabilities

### New Capabilities

- `foreca-forecast`: получение прогноза Foreca с шагом 3 часа, валидация ответа, сборка доменной модели недели, кэширование и поведение при сбоях и деградации источника данных.
- `weather-chart`: построение и отрисовка кадра недельного прогноза 640x480, включая иконки, кривую температуры, осадки, ветер и обязательную атрибуцию Foreca.
- `rtsp-stream`: публикация кадра как RTSP-потока H.264, две ссылки на один поток, offline-заглушка и устойчивость вещания при сбоях.
- `service-configuration`: конфигурационный файл сервиса, интерактивный мастер первого запуска, проверка токена и локации, неинтерактивный режим для контейнера.

### Modified Capabilities

Нет: спецификаций в проекте ещё не существует.

## Impact

- Новый код: клиент Foreca, декодер/валидатор на zod, построение доменной модели, рендерер кадра, супервизор FFmpeg, запуск и остановка MediaMTX-публикации, мастер конфигурации.
- Новые зависимости: `@hey-api/openapi-ts` (генерация типов и zod-схем), `zod`, `@napi-rs/canvas` (ветка 0.1.x — см. design.md, в 1.x утечка памяти на `data()`).
- Внешние системы: Foreca Weather API (Bearer-токен, квоты), FFmpeg (libx264), MediaMTX (RTSP-сервер), аппаратный NVR.
- Новые артефакты в репозитории: сгенерированные типы и zod-схемы, скрипт нормализации OpenAPI, `mediamtx.yml`, offline-заглушка, шрифт, логотип Foreca, `.gitignore` для конфигурации с токеном.
- Юридическое: отображение логотипа Foreca обязательно по условиям использования API; иконки погоды рисуются собственные, чтобы не зависеть от доступа к My API.
